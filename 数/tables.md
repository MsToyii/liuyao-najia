## 二、性质界定（这三条最容易出错）

### 暗动的三个条件

> **静爻被日建冲，且爻本身旺相，冲之即起，谓之暗动。**

1. 是**静爻**（动爻不叫暗动）
2. 被**日辰**冲（月建冲是月破，不是暗动）
3. 爻本身**旺相**

**验算流程**：查月建定旺衰 → 查日建是否相冲 → 看是否同时被克被合 → 三条全满足才可下"暗动"。

> **★ 存在感 ≠ 动。** 一根爻影响力再大、位置再关键，只要没被日辰冲，就不能叫暗动。想表达"影响大"，用「旺相」「临某六神」「位高」「冲世」这些说法。

### 月破 / 日破

- **月破**：爻与**月建**相冲
- **日破**：爻与**日辰**相冲，**且该爻休囚**
- **破的例外**：月破之爻若得日辰生扶，或逢合、逢填实，可"破而能用"——非常规，需专门说明理由

**★ 动爻被月冲，多主「反复」，不主「彻底破」。**

动爻本身是有力量的。一根动爻被月建冲，读法是**条款推倒重来、事情反复拉扯**，而不是"这件事死了"。判"破"之前先看它动不动、有没有气。

**注意**：旺相之爻被冲是「动」不是「破」。见 `理/principles.md` 第三节。

### 旬空的作用范围

**空亡只作用于旬空的那两个地支本身。**

例：旬空寅卯 → 寅、卯落空，**亥不空**。

**空爻的四个性质**：
- 不受生（别人生它，进不去）
- 不生不克（力量发不出来）
- 冲空则实
- 出空即应期（但出空 ≠ 得用）

## 三、用词纪律

写断卦时，**"X 冲 Y""X 合 Y""X 克 Y"这类断言，写之前查表。**

这是最容易混进正文的硬伤，懂行的人一眼看出来。

### 实战核出的常见错误

| ❌ 错误写法 | ✅ 正确 |
|---|---|
| "巳火冲子水" | 巳与子**不冲**。冲子水的是**午火** |
| "未土合酉金" | 未与酉**不合**。合酉的是**辰**；未土是**生**酉金 |
| "午火冲亥水" | 午**不冲亥**。冲亥的是**巳**；午冲**子** |
| "戌土暗动" | 先验日建是否为**辰**（辰戌冲）。日建非辰，不成暗动 |
| "亥水旬空（寅卯空）" | 寅卯空，**亥不空** |
| "巳火冲世爻"（世为子水） | 子与巳**不冲**。能冲子水的只有**午火** |

## 四、生克方向核对

写生克链时，逐环核对：

- A 生 B，还是 B 生 A？
- 被生 / 被克的那根，是**世爻**？**应爻**？还是**用神**？
- 链条最终流向哪里？

> **方向搞反一次，结论完全反转。** 尤其「世克官」vs「官克世」——前者是"你有权压制它"，后者是"你被它管着"。
