## 二、★ 象要画到"看得见"

**这是最容易退化的一步。** 停在符号层，断出来就是术语堆砌；画到画面层，才有用。

一条象，问三次：

### 第一问：它是谁？
**六亲（身份）＋ 爻位（层级）＋ 六神（做派）** —— 三者一起定。

- 六亲：父母 = 文书/长辈/房子；兄弟 = 同事/竞争者/分钱的人；官鬼 = 领导/职位/麻烦
- 爻位：五爻 = 高层/核心；四爻 = 中层/近领导；三爻 = 平级/转折；初爻 = 基层/起点
- 六神：玄武 = 暗中；朱雀 = 爱说/口舌；白虎 = 强硬/急；勾陈 = 慢/旧；螣蛇 = 缠/虚；青龙 = 正/体面

> 例：兄弟（分钱的人）＋ 五爻（位置不低）＋ 玄武（在暗处）
> → **"一个位置不低、在暗处、卡着这笔钱的人。"**

### 第二问：它现在什么样？
空、墓、动、伏、旺、衰、被冲、被合 —— 这是状态，不是结论。

- 空 = 还没到位
- 墓 = 被收着、被锁着
- 动 = 正在发生、主动发力
- 伏 = 藏着、看得见摸不着
- 旺 = 有劲；衰 = 没劲

### 第三问：在你的现实里，这是什么画面？
**落成一句能想象出来的话。**

| 停在符号层 ❌ | 画出来 ✅ |
|---|---|
| "父母入墓，文书被压着" | "对方把合同压在某个人手里，说好的事又搁下，文件迟迟不往上报" |
| "财伏兄弟下，飞克伏" | "这笔钱被一个分钱的环节扣着，你要一次他不给，要两次他压价" |
| "世爻空" | "你手里现在拿出来的还是概念，没有能拍在桌上的东西" |
| "应爻勾陈" | "对方不急，他在等你先松口" |

**判断标准：这句话能不能让求测人"看见"？看不见，就是没画完。**

## 三、象要叠加，不要罗列

分节陈述是骨架，但结论要从**叠加**里出。

几个符号合起来，是一个画面、一个故事、一个节奏：

> **入墓（被锁）＋ 勾陈（慢）＋ 明夷（暗）**
> = "对方内部有个环节把这事扣着，流程慢，外面还看不清。"

> **世爻空（没落地）＋ 应爻旺（对方有牌）＋ 财伏（钱没出来）**
> = "你拿着一堆想法去谈，对方拿着预算表在等你先出价。"

**做法**：写结论之前，把这几个符号摆在一起，问一句——**"它们合起来，是什么场景？"**

## 四、象有"气的节奏"

象不只说"是什么人什么事"，还说**"什么节奏"**。

- **聚 / 散** —— 是越谈越拢，还是越谈越开
- **升 / 降** —— 势头向上还是向下
- **快 / 慢** —— 急事还是慢事
- **续 / 断** —— 一口气推到底，还是走走停停

参考 `zuhe.md` 第五节「气机流转」。

**这决定你给建议的调子**：
- 气是聚的、快的 → 建议"抓住窗口，一次推到底"
- 气是散的、慢的 → 建议"别硬推，等它自己收拢"

## 五、象和数的分工（再强调一次）

- **象负责生成** —— 可能是什么人、什么事、什么画面
- **数负责验证** —— 这个解读在卦里有没有依据

**取一个象，就要在卦里找到依据。找不到依据的象，作废。**

例：
- 取象「这个职位藏在你身边」→ 验：官鬼伏于世爻之下 ✓
- 取象「这个职位会从南方来」→ 验：卦里没有这个依据 ✗
