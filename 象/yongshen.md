# 象 · 用神取法

**问什么，取什么。** 用神定了，取象才有靶心。

这一层给的是"**对应的表**"和"**取法的依据**"，不是"必须取哪一根"的判决。

> **用神错了，全盘皆错。**（`理/principles.md` 第十二节）
> 但也别把用神当成唯一答案——**它是取象的起点，不是推演的终点。**

## 一、按事类取用神

这张表按"**所问之事**"取用神。

> **与 `象/liuqin.md`「六亲对号入座」的分工**：
> 那张表按"**你的身份背景**"映射六亲（保险业务里谁是父母、谁是官鬼）；
> 这张表按"**你问的事**"取用神（问姻缘取什么、问官司取什么）。
> **两张表配合用**：先按事类定用神的大方向，再按背景把六亲落到具体的人和事上。

## 二、用神多现时怎么取

同一个六亲在卦里出现两次甚至三次，取哪一个？**这不是硬规定，是一组"看哪根更贴题"的依据。**

| 依据 | 倾向（多数情况下） |
|---|---|
| **动者优先** | 动爻是用神的"**活跃版本**"，是事情正在发生的那一面。静的那根更像背景 |
| **临世应者优先** | 直接和卦主或对方挂钩的，更能代表"这次的事" |
| **旺者优先** | 力量最强的那根，更可能"说得上话" |
| **位高者 / 近世者** | 居五爻、上爻的常读"上位的、远端的"；贴世爻的读"贴身的、手边的"（详见 `象/yaowei.md`） |
| **明现优先于伏藏** | 上卦的用神摆在明面上，伏神藏在底下，先看明面的 |
| **临日月者为要** | 被日月所临的那根，此刻最有气，最当令 |
| **变爻中的用神** | 主卦定当下、变卦定走向，变出的用神标的是"事情会变成的那一面" |

### 两种特殊情形

**① 空破的用神**
空破不等于"没有"（`理/principles.md` 第二节）。它可能是：
- **时候未到**——名分还没到，出空之时就是应期
- **虚了、散了**——问凶事时，空破的用神代表这事本身就虚

**取哪一层，看所问是吉事还是凶事、看它在什么处境。**

**② 两爻同现**
同一个六亲两现，常常意味着"**两件事、两个人**"。要分别定性，不能混读：
- 两财同现：可能是"一为预算、一为支出"，或"你和他各有一份钱"
- 两官同现：可能是"一为直属领导、一为高层"，或"两个岗位"
- 两父母同现：可能是"一为当前合同、一为下一份"

**多现之爻若都不动、都不临世应**，画面可能是"**所问之事另有并行的人或事，还藏在暗处**"——在输出里点明，别漏。

## 三、用神不上卦（伏神）

**六亲不上卦**时（比如问事业，卦里却没有官鬼），要到**本宫首卦（八纯卦）**的同一爻位上，去取伏神。

**原理**：每一宫的首卦（八纯卦）六亲齐全，是这个宫的"底版"。本卦缺的那一亲，就藏在底版同一爻位之下，是为**伏神**，压着它的那根叫**飞神**。

### 八纯卦 · 六亲全表（找伏神用）

下表每格为「纳甲 + 六亲」。查法：先定本卦属哪一宫，再到对应首卦的**同一爻位**取六亲即得伏神。

| 宫 | 首卦 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 上爻 |
|---|---|---|---|---|---|---|---|
| **乾宫** | 乾为天 | 甲子水·子孙 | 甲寅木·妻财 | 甲辰土·父母 | 壬午火·官鬼 | 壬申金·兄弟 | 壬戌土·父母 |
| **兑宫** | 兑为泽 | 丁巳火·官鬼 | 丁卯木·妻财 | 丁丑土·父母 | 丁亥水·子孙 | 丁酉金·兄弟 | 丁未土·父母 |
| **离宫** | 离为火 | 己卯木·父母 | 己丑土·子孙 | 己亥水·官鬼 | 己酉金·妻财 | 己未土·子孙 | 己巳火·兄弟 |
| **震宫** | 震为雷 | 庚子水·父母 | 庚寅木·兄弟 | 庚辰土·妻财 | 庚午火·子孙 | 庚申金·官鬼 | 庚戌土·妻财 |
| **巽宫** | 巽为风 | 辛丑土·妻财 | 辛亥水·父母 | 辛酉金·官鬼 | 辛未土·妻财 | 辛巳火·子孙 | 辛卯木·兄弟 |
| **坎宫** | 坎为水 | 戊寅木·子孙 | 戊辰土·官鬼 | 戊午火·妻财 | 戊申金·父母 | 戊戌土·官鬼 | 戊子水·兄弟 |
| **艮宫** | 艮为山 | 丙辰土·兄弟 | 丙午火·父母 | 丙申金·子孙 | 丙戌土·兄弟 | 丙子水·妻财 | 丙寅木·官鬼 |

> **例**：本卦属巽宫，卦里无官鬼（问事业）。查巽为风——三爻为「辛酉金·官鬼」。则伏神是三爻位的辛酉金，压在它上面的飞神是三爻。

### 伏神与飞神的关系怎么读

**伏神能不能"出来"，看两件事**（`理/principles.md` 第四节）：**伏神自身旺不旺**、**飞神压不压得住**。

| 伏飞关系 | 可读作 |
|---|---|
| **飞生伏** | 明面上的人在养着暗处的事 → 有靠、能出来 |
| **伏生飞** | 暗处的事在供给明面上的事 → 内里往外交 |
| **飞克伏** | 明面上的力量压着暗处的事 → **被压住**，出不来 |
| **伏克飞** | 暗处的能力反制明面的 → 有翻盘的底子 |
| **伏飞比和** | 表里同气 → 内外一致，藏和显是一回事 |
| **飞神空** | 盖子没了 → **伏神易出** |
| **飞神被冲、被克、入墓** | 压不住了 → **伏神有机会** |
| **伏神临日月** | 伏神极旺 → 藏不住，早晚要出来 |
| **伏神临世爻之下** | 这事藏在**你自己的状态里**，是你心里还没决的事 |
| **伏神紧贴本爻之旁** | 事情其实就在明面上，只是你还没看见 |

**要提醒自己的是**：「藏而不出」只是伏神的**一种**常态，不是全部。**伏神旺 + 飞神受制 = 事情藏不住，会出来，这是吉象。** 别一见伏神就读"出不来"。

## 四、兼看的原则

以下都是"**通常要看**"、"**可以参考**"，不是"必须"。参考着看，别把自己绕进去。

### 兼看世爻

**这是最常见的一条兼看。**

- 用神讲"**事**"的状态，世爻讲"**你**"的状态
- 事再吉，世爻衰败无力承接，也落空
- 事有阻，世爻旺相有力，往往还能扭转

多数情况下，**两个都要看**：事成不成看用神，你接不接得住看世爻。

### 兼看应爻

应爻通常代表**环境与对方**。

- 问"某人对我的影响" → 应爻就是那个人
- 问"这个环境如何" → 应爻就是这个环境
- 世应的生克，读主导权与相处的味道（详见 `象/zuhe.md` 第二节）

### 兼看同类六亲

用神之外，和它同六亲的那一根，可以参考：
- 两财同现，一根是"要赚的钱"，另一根可能是"要花的钱"
- 两官同现，一根是"现任"，另一根可能是"候选"

**参考用**，用来分辨"人或事有几份"，不必强求。

### 兼看动爻与变爻

- **动爻**：事情的**变量**在哪、气往哪流
- **变爻**：事情**会变成什么**（主卦定当下、变卦定走向）

用神不动而旁爻动，变量往往在那根旁爻上。

### 兼看日月对用神的生克

用神旺衰，最终要落到**月建、日辰**给它的是什么：
- 得日月生扶 → 有气、站得住
- 被日月克制 → 受制、使不上劲
- 临月建、临日辰 → 极旺

**这是"象"和"数"的接口**——取出来的象，最后要到日月这里验一验。（`数/tables.md`）

### 兼看身份：代占时留个心

**代占（替别人问）时，世爻是"你"，用神才是"被占的那个人"。**

两者身份不同，别混用。
> 例：代占同事的面试——用神取父母（面试、通知），代表的是**同事的事**；世爻代表的是**代为求测的你**。不要把世爻当同事看。

### 一句总纲

**兼看是"补充信息"，不是"另立一个用神"。**

主用神只有一个，其余都是围着它补充线索。兼看多了会散——**用得着就兼，用不着一笔带过。**

## 附：取用神的三步

1. **认事**——先问清"你到底问什么"。同一句话，问法不同，用神不同。（问"这份工作好不好"和问"这份工作能不能拿到"，一个偏官鬼与父母，一个偏父母与世爻）
2. **取神**——按事类表定主用神。
3. **展开**——定了用神，接下来是**象**的活儿：这个用神代表的人事物，**此刻是什么状态、什么处境**。这是 `象/liuqin.md`、`象/zuhe.md` 干的事，不是在这一层解决的。

> **用神是锚，不是终点。** 锚定了，船要怎么走，还得看风、看水、看气。（`象/zuhe.md` 第五节）
