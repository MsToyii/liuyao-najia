# 象 · 爻位

**这一层是素材库，不是结论库。**

爻位是**位置**。位置本身不产生吉凶，只提供联想方向。同一根爻，从不同维度看是不同的东西——它同时是空间的（在哪）、时间的（哪一段）、身体的（哪一部位）、社会的（哪种角色）。

**用法**：看到一个爻落在某位，先把**各个维度**的可能性都摊开，再看哪几个和所问之事咬得上。位置给的是"方向感"，不是"答案"。

**纪律**：这里只写"这一位**可以**是什么"，不写"这一位**就是**什么"。**尤其不要写"初爻动就是事情刚开始"**——那是把位置固化成了结论。位是坐标，不是判词。

> 位与位之间的关系（相应、得位失位）只列现象，怎么用由你按所问之事决定。

---

## 一、三才爻位（天 · 地 · 人）

六爻分三组，每组两爻。

| 爻位 | 三才 | 象 |
|---|---|---|
| 初、二 | **地** | 基础、根基、底层、现实条件、物质、地形、承载 |
| 三、四 | **人** | 人事、当事人、中间层、人的作为、行动、交接处 |
| 五、上 | **天** | 高位、上方、外部环境、天时、大势、精神层面、超出人力之处 |

**注意**：三才是"由下往上"的分层。地在下为承载，人在中为作为，天在上为笼罩。问人事，重心多在三、四；问根基条件，看初、二；问天时大势、外部环境，看五、上。

---

## 二、人体爻位

**这是问健康、问伤灾时最常调用的维度。**

| 爻位 | 部位 | 细分象 |
|---|---|---|
| 初 | **脚、足、趾** | 脚趾、足底、踝、下肢末端 |
| 二 | **小腿、股** | 小腿、膝、大腿、胫骨 |
| 三 | **腰、腹、臀** | 腰、腹、臀部、下腹、骨盆 |
| 四 | **胸、背、心** | 胸、背、心口、胁、肺 |
| 五 | **头面、口** | 头、面、五官、口、耳鼻 |
| 上 | **头顶、发** | 头顶、颅顶、发、百会 |

**用法**：问哪里不舒服，先看动爻落在哪一位，再看该爻的五行、地支，两者叠加定位。**初为下、上为上，是取象的方向感。**

## 三、时序爻位

**同一卦里，六爻可以是同一件事的六个时间切片。**

| 爻位 | 时序象 | 展开 |
|---|---|---|
| 初 | **初始、开端** | 起头、萌芽、第一步、最早的阶段、童年 |
| 二 | **渐长、进展中** | 刚上轨道、渐入、稳定推进、逐渐成形的阶段 |
| 三 | **过半、中程** | 走到一半、转折点、进退交界的阶段 |
| 四 | **近期、接近** | 快到了、眼下这一步、临门前的阶段 |
| 五 | **当前高位、鼎盛** | 眼下正处的位置、正当时、最盛的那一段 |
| 上 | **末端、过往** | 尾声、收尾、已成定局的部分、已经过去的那一段 |

**注意**：这套顺序是"由下往上 = 由早到晚"的一种读法，**不是唯一读法**。也可以"由初到上 = 由近及远""由内及外"。**同一卦，方向由所问之事决定。**（另见第四节空间维度）

## 四、空间爻位

两个层面：**上下**与**内外**。

### 上下

| 爻位 | 空间象 |
|---|---|
| 初 | 最下、最低处、内部、起点、脚下 |
| 二 | 下方、近处、基础层 |
| 三 | 中部、内外的交界 |
| 四 | 上方、稍远、接近顶的位置 |
| 五 | 高处、上位、核心所在的层面 |
| 上 | 最上、最外、顶端、边缘、界外 |

### 内外（内卦 / 外卦）

| 分组 | 爻 | 空间象 |
|---|---|---|
| **内卦** | 初、二、三 | 内、近、自家、内部、己方、近处、本国、本单位 |
| **外卦** | 四、五、上 | 外、远、他方、外部、对方、远处、异地、外单位 |

**用法**：问"东西在哪儿""人从哪来""事情是自己这边还是对方那边"，看内外卦。

## 五、家庭爻位

**问家事、问六亲关系时调用。** 各家说法略有出入，这里只列常见的一组。

| 爻位 | 家庭象 |
|---|---|
| 初 | 幼儿、子孙、晚辈、家中最小的、根基 |
| 二 | 妻、宅、家中主内的、居所 |
| 三 | 兄弟、同辈、家中平辈 |
| 四 | 母、近亲、家中主事的内眷 |
| 五 | 父、夫、家主、主事的当家人 |
| 上 | 祖、长辈、家里最老的一辈、退居的尊长 |

**注意**：这一组是**取象的方向**，不是铁律。求测人的家庭结构不同，映射随之调整——**问清家庭背景再套**。（家庭映射的通用思路见 `象/liuqin.md` 的"对号入座"）

## 六、社会爻位

**问职场、问组织、问上下关系时调用。**

| 爻位 | 社会象 | 展开 |
|---|---|---|
| 初 | **基层、新人** | 一线、入门者、资历最浅、末端执行 |
| 二 | **办事层** | 具体经办、主管办事的人、中层事务岗 |
| 三 | **中层、转折位** | 承上启下、中层、夹在中间、进退关口 |
| 四 | **近领导层** | 身边人、副手、接近决策圈的层 |
| 五 | **决策层、一把手** | 最高的那位、拍板的人、主导者 |
| 上 | **退休、外部、虚位** | 已退、元老、外部顾问、有名无实的位、圈外人 |

**用法**：谁在哪个位置，决定他在组织里"能做什么、受谁管"。**位置高不等于有权，位置低不等于无关。**

## 七、爻位高低与事情层次的对应

把"位"理解成**事情的层级坐标**，而不是吉凶刻度。

- **位高** → 象：层面高、决策性强、看得远、离得远、责任重、脱离具体执行
- **位低** → 象：层面低、执行性强、贴近现实、离得近、根基处、被上级笼罩
- **居中（二、五）** → 象：**得中**。二为内卦之中，五为外卦之中，两端之间、不走极端的位置
- **居端（初、上）** → 象：**过与不及**。初为最下最初，上为最上最终，皆是"界"上的位置

**位与事的对应原则**：

1. **位看的是"层次"，不是"好坏"。** 五位是层级高，不代表吉；初位是层级低，不代表凶。
2. **世、用神落在什么位，象这件事处于什么层面。** 落低位象基础层的事，落高位象决策层的事。
3. **位要和大背景对齐。** 一个公司的"五"和一个班组的"五"，层级含义不同。**先问清是什么层面的事，再定位。**

### 位之间的结构（只列现象）

- **应位**：初↔四、二↔五、三↔上，两两相应。呼应、牵动、往来多在这三对上取象
- **得位 / 失位**：阳爻居初、三、五（阳位），阴爻居二、四、上（阴位），为**当位**；反之**失位**。位之当否只作现象看，吉凶由整体态势定
- **上下卦对应**：内卦三爻与外卦三爻各居其位，可作"内部三层"与"外部三层"的对照

**注意**：应、当位这些只是**结构现象**。它们说明"这两处有关系"，不说明"结果如何"。结论要靠象与数共同支撑，不能靠结构本身推。

## 收尾提示

爻位的用法，一句话：**先把位置翻译成"它在哪里、什么时候、身体的哪里、社会上的谁"，再让所问之事去挑选。** 位是素材里最"中性"的一类——它几乎不含判断，正因如此，**最容易在不知不觉间被读成结论。** 落笔前对自己过一遍：我是在用这个位**定位**，还是已经用它**定罪**了？
