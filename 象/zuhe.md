# 象 · 组合取象与气机流转

**这一层是素材库，不是结论库。**

单看一个六亲、一个六神，只是一块料。把几块料**叠起来**，才开始出画面。但叠出来的，仍然是"**可能**是什么"，不是"**就是**什么"。

取哪一个画面，回到**所问之事**和**求测人的实际处境**。

**用法**：看到一个组合，先把可能的面相都摊开，再看哪几幅画和现实咬得上。**别一看到组合就锁定一个故事。**

## 一、六亲 × 六神 三十象

同一根父母爻——临青龙是"体面的文书"，临玄武是"见不得光的文书"。**同一个东西，换了颜色就换了故事。**

- **颜色不等于吉凶。** 吉凶要看旺衰生克（`理/principles.md`、`数/tables.md`），六神只回答"这件事长什么样"。

## 二、世应之间的象

**世爻是主体**（你、己方、自己所处的位置）。**应爻是对方、环境、结果**。

世应之间是什么关系，读的是**"这两方此刻是什么味道"**——不是吉凶，是**关系质感**。

| 世应关系 | 关系质感（画面） |
|---|---|
| **世克应** | 你这边主动、拿得住对方。但**克是消耗**——你要为它费心、费劲，是"我按住它"，不是"它顺着我" |
| **应克世** | 对方压着你，你被推着走。被动、承压、由不得你 |
| **应生世** | 对方往你这边使劲，来帮你、给你东西、向你有靠拢之意。**有人托着你** |
| **世生应** | 你往对方那边淌、投喂、付出。往好处说是投资，往坏处说是被抽血 |
| **世应比和** | 同气、对等、无落差。可以是气味相投，也可以是各顾各的平行关系 |
| **世应相冲** | 两股劲对冲，天然不咬合、错位。来回拉扯，你进它退 |
| **世应相合** | 缠在一起、黏着。亲近、有羁绊，事情不易了断 |

**再看位置**：世应各在什么爻位（详见 `象/yaowei.md`），谁在上谁在下、谁在内谁在外，也带信息。
- 世在**内卦**、应在**外卦**：内里是自己的事，外面是对方的地盘
- 世在**五爻、应在上爻**：你居核心，对方在远端
- 世应**紧挨**：两方离得近，接触频繁，关系紧

**注意**：世应之间的"冲合"要查 `数/tables.md` 核对地支，别把不合写成合、把不冲写成冲。

## 三、两爻之间的组合

两爻叠起来，生成的是"**这两方此刻的相处画面**"。看三种位置：

### 1. 相邻两爻

紧挨着的两爻，是"**贴在一起的两个人/两件事**"。

> 五爻是决策者、上爻是更上层的长辈——两爻相邻，画面是"这个人就挨着权力中心"。
> 三爻是平级、四爻是近君之位——两爻相邻，画面是"平级的人就在门边上，能穿话"。

相邻两爻的生克，读"谁贴着谁、谁在给谁递东西"。

### 2. 上下卦对应爻（初四、二五、三上）

内卦与外卦同一序位的一对爻，读"**表与里、下与上**"。

- **初 ↔ 四**：根基与门户，下层与中层
- **二 ↔ 五**：内卦之中与君位，家宅/基础与决策核心
- **三 ↔ 上**：人位与终端，行动的与收场的

这两爻的关系，常读作"**下面的东西在上面的处境**"或"里子和面子的落差"。

### 3. 世应之间的那一串爻

世应之间隔着几根爻，那几根爻就是"**你和对方之间的路**"。

- 中间是**父母**：中间隔着文书、流程、手续
- 中间是**官鬼**：中间隔着权威、规则、审批的人
- 中间是**兄弟**：中间有竞争者、有人在中间分东西
- 中间是**妻财**：中间牵着利益、钱
- 中间**空**或**动**：这条路是断的、或正在起变化

同一根爻，**挨着谁、冲谁、生谁**，画面都不同。两爻组合没有标准答案，看的是它在你眼前拼成了什么。

## 四、上下卦之间的象

把卦拆成上下两个单卦来读。这是最快出"大画面"的方法。

### 各代表什么领域

| | 上卦（外卦） | 下卦（内卦） |
|---|---|---|
| 空间 | 外、上、远、台面 | 内、下、近、里子 |
| 人事 | 对方、外部力量、上级、环境 | 自己、内部、根基、家 |
| 时序 | 后段、结果段 | 前段、起因段 |
| 姿态 | 显露的、在外的动作 | 潜藏的、内在的动机 |

**读法**：上卦是"外面这一层"，下卦是"里面这一层"。两卦一碰，先看它们的**五行关系**（查 `象/dizhi.md`、`数/tables.md`）：

- **下生上**：内里的东西往外面送（我供给对方、根基托着局面）
- **上生下**：外面的东西往里面流（外部给资源、环境滋养内部）
- **上克下**：外部的力量压着内部（环境压自己、对方压你）
- **下克上**：内部反过来顶外部（自己去冲环境，费劲）
- **上下同气**：内外一致，同进同退

### 常见的上下组合画面

| 上下 | 卦 | 画面 |
|---|---|---|
| **乾上坤下** | 否 | 天往上飘、地往下沉，背道而驰 → **上下不交**，隔阂、僵住 |
| **坤上乾下** | 泰 | 地气上升、天气下降，对流 → **上下交通**，顺畅、通 |
| **离上坎下** | 未济 | 火往上、水往下，各走各的 → **水火不交**，尚未交汇、事未成 |
| **坎上离下** | 既济 | 水在上、火在下，各安其位、相交 → **水火既济**，事已定 |
| **震上巽下** | 恒 | 雷动风随 → 长久的往来 |
| **巽上震下** | 益 | 风助雷势 → 增益、加力 |
| **艮上兑下** | 损 | 山压泽上 → 减损、被压 |
| **兑上艮下** | 咸 | 泽在山上、山泽通气 → 感应、一拍即合 |
| **巽上坎下** | 涣 | 风行水上 → 涣散、人散事淡 |
| **坎上巽下** | 井 | 水在风中藏于下 → 根基不动、要费辛劳守着 |

**这两个卦的"关系"比两个卦"分别是什么"更重要。** 别只读"上卦是乾=领导、下卦是艮=山"，要读"**领导在上不动，山在下想动**"——这一碰，画面就活了。

> 单卦本身的卦名象义见 `象/guaming.md`，这里只讲**两者相碰**生出的东西。

## 五、★ 气机流转

前面四节是**静态**的取象。这一节讲**气在走**。

**气机不是旺衰标签，是"这件事的节奏与走向"**——它从哪儿生、往哪儿走、快还是慢、聚还是散。

### 1. 月建的气：当令之气怎么推移

十二个月的"当令之气"，是这一季、这一月的**底色**：

| 月建 | 当令 | 气的性质 |
|---|---|---|
| 寅 | 木 | 初生之气，破土向上，急而**不稳** |
| 卯 | 木 | 木气正位，舒展、**外放** |
| 辰 | 土（木余） | 木气入库，**转承**之月，气开始收 |
| 巳 | 火 | 火气初起，**往上、发热** |
| 午 | 火 | 火至极位，盛极，**阳极将转** |
| 未 | 土（火余） | 火气入库，燥气**转承** |
| 申 | 金 | 金气初起，**往下、收敛**、肃杀 |
| 酉 | 金 | 金气正位，清冷、**锋锐** |
| 戌 | 土（金余） | 金气入库，气**归藏** |
| 亥 | 水 | 水气初起，**润下、隐藏** |
| 子 | 水 | 水至极位，至静至暗，**一阳将生** |
| 丑 | 土（水余） | 水气入库，气**最沉**，将转 |

**气机的进退**，可以借十二消息卦看：

> 子月**一阳来复**（气沉到底，开始冒头）→ 寅月**三阳开泰**（气最顺、万事可动）→ 巳月**六阳极盛**（满，将溢）→ 午月**一阴生**（气开始退）→ 亥月**六阴**（气最敛）。

**用法**：问"什么时候"的时候，看的是**气正走到哪一程**——是在升的初段，还是在降的末段？**升之初最宜动，降之末最宜守。**

### 2. 日辰的气

日辰是"**当下这一刻的气**"，是今天的天气。

- 日辰**生扶**某爻 → 这根爻此刻**有气、站得稳**
- 日辰**克制**某爻 → 这根爻此刻**受制、使不上劲**
- 日辰**冲**某爻 → 事**在动**（旺者冲之即起，休囚者冲之即散，见 `理/principles.md` 第三节）

日辰比月建更"当下"，月建定气的大势，日辰定**此刻这一步**。

### 3. 动爻如何带动气的流向

**一根爻动，就是往平静的水面丢了一颗石子。** 气从这根爻开始，顺着生克的链条往外扩散。

读动爻，读三件事：

1. **它生谁、克谁** → 气往哪个方向流
2. **它化出什么**（变爻） → 气流到最后变成了什么
3. **它离谁近** → 谁先吃到这股气

**多爻齐动**：气从几个口子同时往外冒——画面是"头绪多、各方都在动、难以收束"，未必是吉。

**静卦**：没有石子入水，气是**平缓地淌**，看的是用神本身有没有气、日辰月建给不给力。

### 4. 气的"聚"与"散"、"升"与"降"

| 气的形态 | 由什么而生 | 画面 |
|---|---|---|
| **聚** | 三合局、六合、众爻归于一 | 力量汇集、凝成一股、事在凑成 |
| **散** | 冲、泄、众爻各奔 | 力量分散、各走各的、事在拆解 |
| **藏** | 入墓、伏藏 | 气收起来、暂时收着、时候未到 |
| **升** | 木火之气、往上往外 | 气在发、在长、在显露、有冲劲 |
| **降** | 金水之气、往下往内 | 气在收、在落、在潜藏、肃杀 |
| **滞** | 土、勾陈、被合 | 气在中途卡住、黏着、走不动 |

**升降失衡**的画面：上热下冷（上面火气旺、下面水气沉）→ 头重脚轻、上面着急下面不动；反之则是根基在动而台面无声。

### 5. 气机对事的节奏

**这是"快慢、缓急、断续"的素材**——不是"快就好、慢就坏"：

| 气的特征 | 事的节奏 / 给人的感觉 |
|---|---|
| 旺相、临日月、得生扶 | **急、快、有力**，事在往上走 |
| 休囚、无生扶、被克 | **缓、慢、无力**，事在往下沉 |
| 逢日辰冲、马星动、动爻发 | **快**，事在动、在来 |
| 逢合、入墓、临勾陈土 | **慢**，黏住、拖延、卡着 |
| 旬空 | **断一下**——暂时停住、名分未到（不是没有，见 `理/principles.md` 第二节） |
| 伏藏 | 气**在暗里走**，不显于外 |
| 一气相生成链 | **一条线推进**，顺、连贯 |
| 气到处受克 | **走走停停**，处处受阻，费劲 |
| 三合局成 | **集中发力**，力量汇成一股 |
| 冲散无归 | **各奔东西**，散、不成局 |

**一句话概括这一节**：旺衰回答"**力量多大**"，气机回答"**在往哪走、走得顺不顺、走得快不快**"。两件事都要看。

## 附：这一层怎么用

组合取象是**生成画面**的活儿，不是**下判决**的活儿。用它的时候，问自己三句话：

1. **我摊开了几种可能？** 一个组合只读出一个故事，通常是读窄了。
2. **这些可能里，哪几个和求测人的实情咬得上？** 咬不上的，先放下。
3. **我在卦里找得到依据吗？** 找不到依据的画面，作废（`理/principles.md` 第十一节）。

**象生成可能，数筛掉站不住的，理的把握方向。** 顺序不能反。
